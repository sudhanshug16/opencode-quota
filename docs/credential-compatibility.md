# Existing OpenCode credentials: source-backed compatibility

This table concerns **credentials already connected in OpenCode V2**, not every CodexBar provider. A matched active connection is still conditional on its permissions, account and endpoint. No live credentials or paid APIs were queried. [OpenCode V2 provider docs](https://opencode.ai/v2/docs/providers) describe its models.dev catalog; the [plugin contract](https://opencode.ai/v2/docs/build/plugins#integrations) exposes an active connection and resolved key/OAuth credential. `docs/opencode-scope.json` maps the pinned upstream registry to that catalog; it is not a claim that every mapped acquisition path accepts an OpenCode credential.

**Count:** eight subscription quota-window families (Go, Codex OAuth conditional on wham audience/entitlement, GitHub Copilot public-host device OAuth, z.ai, ClinePass, Kimi Code, Chutes, Neuralwatt); v0 adds distinct provider-unit billing/rate windows. OpenRouter, DeepInfra, Venice and Hugging Face have **conditional spending/epoch caps only when configured and readable**. DeepSeek, Moonshot, Poe, Hyper, Venice and Neuralwatt have balances; Fireworks, Hugging Face and Neuralwatt have spend. These are source/fixture capabilities, **not** live compatible accounts. Of 22 implemented provider families, eight have a source-aligned stored credential/endpoint path (Go, z.ai, OpenRouter, DeepSeek, Moonshot, Copilot, Poe, Hyper); fourteen are conditional on audience, plan, scope or billing permission (Codex, ClinePass, Kimi, Chutes, Fireworks, DeepInfra, v0, Venice, Hugging Face, Neuralwatt, Synthetic, MiniMax, Kilo, Alibaba Coding Plan). No family has live credential acceptance proof. The other 21 mapped families have no collector, which is distinct from proving their stored credentials unusable. Admin spend (OpenAI), xAI management/team billing, browser cookies and CLI logins do not become available just because an inference key is stored in OpenCode. OpenCode Anthropic remains eligible; Claude Code-specific credential acquisition is excluded. [The route triage](route-triage.json) separates remaining capabilities, alternatives and non-quota paths.
