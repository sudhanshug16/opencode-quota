# Upstream maintenance

`upstream.json` pins CodexBar's registry and provider/plugin source trees. `docs/parity.json` lists every first-party registry ID and its acquisition routes; `supported` lists only ported strategies with a fixture. The weekly workflow compares the pinned SHA to upstream HEAD, reports changed provider and bundled-plugin files, and fails closed if GitHub truncates the comparison. It neither copies code nor silently updates the pin. For each update, compare the generated registry and descriptor strategies, reconcile additions/removals, inspect auth/account and field changes, refresh sanitized fixtures, then advance the pin and run `bun run check`. CodexBar's MIT license applies to reviewed behavior; no source is vendored.
